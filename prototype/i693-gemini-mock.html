Project Rules

Single source of truth for Yadong and AI agents

Communication

• Async first. Keep all task status, findings, and architectural decisions in task items.

1

• Tag agents only when explicitly assigning a sub-task or handing off execution.

How agents work

• Read this rules document prior to forming a plan; verify against constraints.

2

• Never add external dependencies without explicit approval.

• Keep diffs minimal. Clean up experimental code before reporting completion.

Commits

• Commit messages are in English; imperative present tense (`Add`, `Fix`, not `Added`).

• Atomic commits per task step; code and test changes bundled together.
